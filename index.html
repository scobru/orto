Your workspace.
Your server. Your data.

ZenOS is a self-hosted personal workspace: encrypted notes, calendar, bookmarks, tasks, contacts, secrets, files and a public blog, on one small Node server with a single SQLite file. Everything private is encrypted in your browser with a key derived from your username and password; the server only stores ciphertext.

Run your server Install CLI / SDK

What it does

🔒 Vaultvault

Markdown notes, tags, checklists. AES-GCM-256 encrypted in your browser; the server sees only ciphertext.

📋 Taskstasks

Encrypted Kanban board with columns, priorities, due dates, and note cross-links.

📅 Calendarcalendar

Encrypted events and agenda, linked to Vault notes.

🔖 Bookmarksbookmarks

Private library with folders and tags. Import/export Brave, Chrome, Firefox HTML.

👥 Contactscontacts

Encrypted address book with tags and an optional ZenOS username per contact. Import and export vCard (.vcf).

🔑 Secretssecrets

Passwords, API keys and secure notes, encrypted before they leave your browser. Hidden by default, with a password generator.

📁 Filesfiles

Upload any file. Encrypted in the browser, stored on your server's disk, with a per-user quota.

🪶 Blogposts

Public Markdown blog at /blog/<username>.

One login works in the web app, the CLI and the SDK. AI agents can read and write the same data through the SDK.

Install

Needs Node 22.5+ (built-in SQLite). No npm packages.

git clone https://github.com/scobru/zenos.git
git clone https://github.com/scobru/zenos-web.git
cd zenos && npm start          # http://127.0.0.1:8787

Open the URL, pick a username and password; the app offers to create the account on first login. Put it behind HTTPS (Caddy, nginx) before exposing it.

The password is the only key to your data. Lose it, lose the data. No recovery.

Use

  1. Log in on your server's web app. Write notes, add events, import bookmarks and contacts, store passwords, upload files, publish posts.
  2. Script it with the CLI:
node cli.js vault-write --user alice --pass secret \
  --title "Idea" --body "- [ ] ship it" --cat research
node cli.js vault-read  --user alice --pass secret --query idea
node cli.js bookmarks-import --user alice --pass secret --file bookmarks.html
node cli.js contacts-import --user alice --pass secret --file contacts.vcf
node cli.js secret-add --user alice --pass secret --name GitHub --generate
node cli.js file-upload --user alice --pass secret --file photo.png
node cli.js blog-publish --user alice --pass secret \
  --title "Hello" --content "First post" --tags "zenos,notes"
node cli.js blog-read --alias alice

Or the JavaScript SDK:

import ZenOS from './zenos.js';
const os = new ZenOS();   // default server: https://zenos.scobrudot.dev
await os.login('alice', 'secret');
await os.writeVaultNote({ title: 'Hi', body: 'Encrypted.', cat: 'logs' });
await os.writeCalendarEvent({ title: 'Standup', start: Date.now() + 36e5 });

Agents: see llm.txt for the integration guide.

Server

One file, server.js: an HTTP API, live updates (SSE), SQLite storage and an uploads folder. Back up the data/ folder and you have backed up everything. Settings are environment variables (PORT, ZENOS_DATA, ZENOS_REGISTRATION=closed, ZENOS_QUOTA, ...), listed in the README.

The operator sees usernames, record ids, timestamps, sizes and IPs, never contents.
